小雅刷课助手 0.3.0（Chrome / Microsoft Edge 120 及以上）

安装
1. Chrome 打开 chrome://extensions/；Microsoft Edge 打开 edge://extensions/。
2. 打开右上角“开发者模式”。
3. 点击“加载未打包的扩展程序”。
4. 选择本目录中的 extension 文件夹，勿选择整个项目目录或 ZIP。
5. 刷新已登录的小雅页面。

Chrome 与 Edge 复用同一份 extension 代码，功能一致。使用 Edge 时在 Edge 内单独登录小雅。
Edge 安装包附有安装-edge.txt；真实 Edge 平台流程尚未完成验证。

使用
1. 在任意网页打开插件，点击“获取待完成任务”，自动前往小雅“我的课程”首页。
   优先复用现有小雅标签页，没有才新建；不会把正在使用的其他网站导航走。
   已登录会自动读取待办；未登录则请手动完成登录，成功后自动继续获取。
   关闭插件弹窗不会丢失等待登录的请求；点击停止或关闭对应小雅页可取消。
   点击扩展的“获取待完成任务”可预览当前可处理的跨课程待办。
   点击“开始队列”会自动打开待办列表、选择“显示全部任务”，保留“仅显示可完成任务”。
   插件只选择自主观看类型的视频和课件，完成一项后返回首页重新读取下一项。
   首页待办之外的任务、未开放任务、讨论、测验及考试不处理。
   也可从课程内部启动：从课程根目录处理其下章节，从具体章节处理该章节及子目录。
2. 点击扩展图标，选择倍速、后台模式和静音选项；课件时长自动读取，无需填写。
3. 点击“开始队列”。关闭弹窗不会停止；点击“停止”才会暂停。
   默认开启“完成后自动打开下一个任务”：当前任务经平台确认完成后自动继续。
   首页启动会返回待办列表选择下一项；课程内启动会打开目录中的下一项。
   关闭该开关则完成当前任务后暂停，保留当前页面。
4. 可以切换其他标签页，需保持 Chrome 和小雅标签页打开、电脑处于唤醒状态。
   只保留启动队列的这一个小雅标签页即可，不会新建额外的小雅页面。
   你可以在同一个 Chrome 中自由打开和使用其他网页；小雅任务在原标签页后台运行。
   完成后在该小雅标签页内自动打开下一任务。
   任务进行中不要刷新、关闭或手动导航小雅页；在其他网页打开插件也能点击停止。
5. 如果浏览器阻止播放，请手动播放一次，或启用“静音自动播放”。

行为与边界
- 自动遍历视频、PPT/PPTX、PDF 和 Word；测验、考试及其他类型跳过。
- 进入具体任务后读取平台返回的完成状态；已完成的任务直接跳过。
- 视频实际播放至结尾后请求完成；课件通过平台正常完成按钮读取该任务的时长要求。
- 平台若返回“已学习 17 秒，至少观看 2 分钟”，再等待剩余 103 秒；
  关闭“知道了”提示后继续计时，时间到后再次请求完成。
- 每份课件单独读取要求；若平台后续返回新的已学习时间或要求，重新计算剩余时间。
- 没有时间限制且平台直接确认完成的任务，立即进入下一项。
- 未返回可识别的时长要求时暂停提示，不采用默认秒数。
- 完成后只有检测到平台“已完成”，才打开下一项；拒绝完成时每 30 秒重试。
- 后台模式临时屏蔽页面的窗口失焦/隐藏事件，并提供前台可见状态，
  以减少前端切屏暂停；不修改播放位置、不伪造学习进度、不直接调用完成接口。
- 后台模式还处理 document.hasFocus 和兼容的 WebKit 可见性属性。
- 小雅页后台运行期间设置为不自动丢弃；停止、正常结束或启动失败后恢复原设置。
  这不能阻止浏览器崩溃、电脑睡眠或用户主动关闭页面。
- 服务端计时限制、浏览器节能/冻结、跨域播放器及后续平台改版可能影响运行。
  暂不保证所有课程在后台都能累计有效学习时间。
- 停止时恢复真实可见性并暂停视频；不会还原用户之前的倍速或静音设置。
- 页面出现验证码、登录失效、加载异常、无法切换时会暂停，需要手动处理。
- 队列仅在当前浏览器会话保存；退出 Chrome 后需要重新启动。
- 一个浏览器配置文件同时只运行一个队列；重新开始会重新扫描完成状态。

验证情况
已检查当前登录课程的视频播放器、任务目录、PPT、完成状态 DOM 和文件夹双击行为。
自动化测试覆盖：服务端未确认不跳转、视频未结束不完成、加载等待、暂停、验证中断、
后台开关恢复、扩展文件完整性、平台时长解析、剩余时长等待、条件更新及未知条件暂停；
首页待办扫描、类型筛选、跨课程资源跳转、平台确认后返回首页及跳转失败暂停。

隐私
仅申请 whut.ai-augmented.com 站点权限、扩展本地存储、定时唤醒和页面脚本注入权限。
页面脚本注入用于检查并修复扩展重载后已打开页面尚未连接的问题，仅限该小雅站点。
不读取或保存登录凭证，不向第三方发送课程或学习数据。
任务状态和最近 40 条日志保存在当前浏览器会话中，设置保存在扩展本地存储中。

开发验证
在项目目录运行：node --test tests/extension.test.cjs tests/worker.test.cjs

从旧版本更新
代码已在原 extension 目录更新。请到 chrome://extensions/ 找到“小雅学习助手”，
点击卡片上的重新加载按钮，然后刷新小雅任务页，再重新开始队列。
旧版保存的固定停留秒数不再生效。

0.1.3 通信修复
获取与启动前检查页面脚本连接，缺失时自动补载；要求页面确认收到启动命令。
失败提示会保存在当前会话中，不再被刷新覆盖成“尚未开始”。弹窗顶部显示版本号。

0.1.6 单标签后台模式
在当前唯一的小雅标签页内执行队列和切换任务，不创建第二个小雅标签页。
补全焦点检测处理，减少自动回收重载；其他网页不受队列控制。
23 项自动化测试通过；尚未对新版进行真实平台后台时长验证。
